# Nova-Retail-Sales-Customer-Analytics

This project simulates the role of a Data Analyst working for Nova Retail, an e-commerce marketplace. The project uses a publicly available marketplace dataset as the raw data source and applies data cleaning, relational database design, SQL analysis, and Power BI to generate business insights.

---
### Business Story:
Nova Retail is a multi-vendor e-commerce marketplace operating across Brazil. The company wants to better understand customer behavior, product performance, seller performance, and sales trends in order to improve business decisions.
